CSS Styles

CSS Styles

Background: Used to set the background colour of the webpage.

Container: Used to set the width of the main content area, centre it on the page, set the background colour and add a black border.

Heading: Used to style the main heading of the webpage by adding padding, a dark slate blue background, white text, a bottom border and bold, large Times New Roman font.

Link Box: Used to create a navigation bar with a dark slate blue background, spacing between links and a black bottom border. Flexbox is used to align the links vertically.

Link Box Links: Used to style the navigation links by adding padding, white bold text and removing underlines. Different colours and backgrounds are applied when links are visited, hovered over, active or selected.

Text Box: Used to style the main content area with padding, a white background, black text, a black border and Times New Roman font.

Tags: Used to display information about HTML tags and CSS styles inside a pale yellow box with padding, a black border and rounded corners.

Paragraphs: Used to add spacing above and below paragraphs within the text box.

Text Box Links: Used to style links within the main content area. Links are displayed inline-block with spacing around them. Their colour changes depending on whether they have been visited.

Lists: Used to style unordered lists with square bullet points, left padding and spacing above and below the list.

List Items: Used to align the text inside list items to the left.

Footer: Used to style the bottom section of the webpage with a dark slate blue background, white text, padding and a black border. The clear property prevents it from appearing beside floated images.

Footer Links: Used to make footer links white and bold while removing their underlines.

Table: Used to make tables fill the available width, add spacing around them, use a white background and combine adjacent borders into single lines.

Table Headings and Cells: Used to add padding and black borders to table headings and cells, while aligning their text to the left.

Table Headings: Used to display table heading text in bold.
