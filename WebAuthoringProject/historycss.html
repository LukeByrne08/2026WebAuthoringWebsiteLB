Introduction

Cascading Style Sheets (CSS) is a style sheet language used for specifying the presentation and styling of a document written in a markup language, such as HTML or XML (including XML dialects such as SVG, MathML, or XHTML). CSS is a cornerstone technology of the World Wide Web, alongside HTML and JavaScript.

(Wikipedia, Wikipedia Contributors ,2023)

CSS 1.0 & 2.0

CSS begins in 1994, when a visionary named Håkon Wium Lie proposed a new language for styling web pages. Fast forward to 1996, and the World Wide Web Consortium (W3C) published the first official CSS 1.0 specification. Back then, CSS was like a baby wizard, with just a few spells in its book:

  • Colour and Background: Basic text and background colours.
  • Font: Limited control over fonts. (Size, Style, and Family)
  • Text Tricks: Simple text alignment and decoration.
  • Spacing: Basic layout controls with margins, padding, and borders.

CSS 2.0 was released in 1998, and a whole new list of features were released:

  • Element Positioning: Static, relative, absolute, and fixed positioning.
  • Z-index: Stack elements on top of eachother.
  • Media Types: Different style rules for screens, printers, and more.
  • Advanced Selectors: Selectors like ":hover." This led to inconsistent browser support. Developers had to use "hacks" to make things work across different browsers.

(dev.to, Ram nathawat, 2024)

CSS 2.1

CSS 2.1 released in 2011. The main goal of this verson of CSS was to fix bugs and ambiguities from CSS 2.0. It brought more stability and control over styling websites. It also provided more browser compatibility.

(dev.to, Ram nathawat, 2024)

CSS 3.0

CSS3 is not a single monolithic release but a collection of modular specifications introduced gradually. These modules cover various aspects of web design, such as animations, gradients, and flexible box layouts.

(dev.to, Ram nathawat, 2024)

Impact of CSS

CSS introduced a clear seperation between content and presentation. With CSS, designers could define styling rules in external style sheets, which could then be applied to multiple HTML documents. This separation of concerns not only simplified the codebase but also made it easier to update and maintain the design of a website.

(linkedin, Razal Kabeer, 2024)
